One export per visitor, build and destination within 30 minutes. DofusBook and JSON file count browsers only: a user agent that names a crawler, or does not start with Mozilla/ as every browser's does, counts nothing there. The API counts every caller but crawlers, browsers and other sites' servers alike. Each server worker keeps its own 30 minutes, so a repeat that reaches the other worker, or comes after a worker restart, counts again. DofusBook counts the export page reaching its link, not the click on that link. JSON file counts the Export as JSON button. Other sites through the API counts each answer of /api/v1/shared-builds/<id>/fashionista-build/, cached ones included, once per calling address and build. Shares are of all exports and add up to 100%.
