{% trans "Frequently Asked Questions" %}

{% trans "Is the Dofus Fashionista free?" %}
{% trans "Yes, it is completely free. There is no paid version, and you can build a set without an account." %}

{% trans "Do I need an account?" %}
{% trans "No. Building and optimizing sets works without signing in. An account only lets you save your projects and share them with a link." %}

{% trans "Is this site made with AI?" %}
{% trans "No. Your set is computed by a mathematical solver, not written by a language model: your priorities become equations and the solver searches every item you have not excluded for the best combination it can find. The code is open source, so you can check for yourself, and the only bot commits in its history are dependency updates. One optional feature does use character recognition: if you import your inventory from a screenshot, a text reader runs in your browser to pick out item names and stats, and you can edit every value before it is used. It never chooses an item." %}

{% trans "Which Dofus version should I choose?" %}
{% trans "Pick the one you play from the buttons at the top: Dofus 3, Beta, Dofus 2, Touch or Retro. Each is a different game with its own items and rules." %}

{% trans "What are the numbers by the sliders? And why does each slider have a different range?" %}
{% trans "Each of those numbers indicate how many points each of the attributes is worth to you. The program will then choose the equipment that sum the most points in total. For example, suppose you have the following equipment:" %}

{% trans "Item A" %}
+ 10 {% trans "intelligence" %}
+ 200 {% trans "initiative" %}
{% trans "Item B" %}
+ 40 {% trans "intelligence" %}
+ 100 {% trans "initiative" %}

{% trans "If you say each intelligence is worth 10 points and each initiative is worth 10 points, equipment A will have a score of 2100 points, while equipment B will have a score of 1400 points, and the program will choose Item A." %}

{% trans "If you say each intelligence is worth 10 points and each initiative is worth 1 point, equipment A will have a score of 300 points, while equipment B will have a score of 500 points, and the program will choose Item B." %}

{% trans "That is our way of telling the program what to optimize. The ranges you see on each slider is the range that is most effective for each attribute, based on our experience. If you wish to use values outside of the range we defined, you can go to the Characteristics Weights page (under More) and set them manually." %}


{% trans "I asked for exos but I can’t find them on any item. Where are they?" %}
{% trans "We don’t assign the exos to any particular equipment because we think you are the best person to know where it is most convenient to have them. Maybe a particular item is cheaper to buy/mage in your server, or you already have an exo in a piece of equipment and want to use it. It is still important that you tell us whether or not you are gonna have exos, because otherwise we may use some items with AP conditions that make them unequipable if you get an extra AP on your set." %}


{% trans "I need a PVM set, but I only see PVP options. Is there a way to build a PVM set?" %}
{% trans "We assume that, if you don’t check either of the PVP options, the set you are building is a PVM set." %}


{% trans "How does the site choose a weapon?" %}
{% trans "If you don’t lock a weapon, the site will disregard the weapon damages and treat it like any other item, so you don’t always get an option that hits well. You will usually get a weapon with good attributes to your build, which tend to hit the element you chose. It is common to get AP weapons that aren’t really for hitting with. Forbid them and run again to see the next better option. " %}


{% trans "Why can I focus on vitality and resists? Doesn't every char need them?" %}
{% trans "Those options are there for characters that need specially high vitality (or resists). For instance, Sacriers, Masqueraiders and Foggernauts may want a lot of vitality and not care much about their main element. Others, like Osamodas, may need a vit/res build with just a little bit of intelligence, and that's how they declare that defense is more important to them. Checking a focus box trades points in your main element (and other stats) for a boost on the focus you chose." %}

{% trans "Not checking any focus boxes is fine and correct for a lot of cases. It will give you an all-around set." %}
