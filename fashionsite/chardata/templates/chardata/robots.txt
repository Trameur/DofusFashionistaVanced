# Crawlers that collect content to train AI models. Blocking them is a
# deliberate choice: the reader gets nothing back when a model is trained on
# this catalogue, unlike a search engine that sends visitors here.
#
# Cloudflare's managed robots.txt used to prepend exactly this list. It only
# reached the apex, so www.dofusfashionista.gg answered with the managed stub
# alone -- nine rules and Allow: / -- and every rule below went unseen by any
# crawler that arrived there. Keeping the list in this file makes the answer
# the same on both hostnames, and puts it under review like the rest.
#
# Assistants that fetch a page because a reader asked for it (ChatGPT-User,
# Claude-User, PerplexityBot, OAI-SearchBot) are deliberately absent: those
# send readers back, and blocking them would cost visits.

# The public content lives at /, /guides/, /encyclopedia/, /sharedbuilds/,
# /s/<build>/, /user/<name>/, /compare_sets/... : all crawlable.
# Everything below is an action endpoint or a per-project/private page: not
# indexable content. Crawling them only wastes crawl budget and fills Search
# Console with 403 / soft-404 / noindex "errors". The */path/ form also covers
# the version-prefixed copies (/beta/…, /dofus2/…, /retro/…, /touch/…).
